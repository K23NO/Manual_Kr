## ¿Qué es KiCad?

**KiCad** es una suite de software de código abierto para el diseño de esquemáticos electrónicos y placas de circuito impreso (PCB). Es utilizada profesionalmente en todo el mundo y cuenta con soporte activo de una gran comunidad.

En **JW Control** utilizamos KiCad como herramienta principal para el desarrollo de nuestros proyectos de electrónica industrial y control.

## Versión de KiCad

Este manual fue elaborado con base en **KiCad 9.0**. Algunas opciones pueden variar en versiones anteriores o posteriores.

!!! tip "Consejo"
    Siempre trabaja con la versión estable más reciente de KiCad para contar con las últimas correcciones y funcionalidades.
